# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository
(the Luciole Audio training, data preparation, export or evaluation code),
please report it privately rather than opening a public issue.

Contact: contact@openllm-france.fr

Please include, if possible:

- a description of the issue and its potential impact;
- the steps to reproduce it (affected files, commands, or inputs);
- any relevant logs or proof of concept.

We will acknowledge your report as soon as we can and keep you informed of the
progress toward a fix. Please allow a reasonable time for the issue to be
addressed before any public disclosure.

This policy covers the source code in this repository. The released Luciole
Audio models and datasets are distributed on the Hugging Face Hub under the
OpenLLM-France organization; issues specific to a published model or dataset
can also be raised there.
